01 / PROJECT OVERVIEW

项目背景、职责与目标

项目背景
随着消费者健康需求从单一疾病管理逐渐转向日常健康管理，健康内容成为品牌与消费者建立长期连接的重要触点。赫力昂通过集团品牌账号输出健康生活相关内容，项目围绕消费者需求、健康趋势与品牌资产，探索不同健康场景下的沟通机会。

我的职责
负责消费者健康趋势研究、竞品内容分析与品牌沟通策略制定，挖掘健康场景与品牌资产之间的连接机会，并输出月度内容规划及创意方向。

项目目标
建立健康需求、生活场景与品牌价值之间的沟通路径，提高集团品牌内容相关性，并增强消费者对旗下健康产品矩阵的认知。

Key Insight / 健康需求与品牌价值连接
